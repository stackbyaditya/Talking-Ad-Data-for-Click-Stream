What a cursor gives away

Anyone can load a page. What is harder to fake is how they move through it. People pause, overshoot, change their mind and drift back to something they already read. Scripts mostly do not.

This page records where your cursor goes, when you click and how you scroll. Twelve measurements come out of that: total distance travelled, the rhythm between clicks, how often you turn sharply, and so on. A gradient-boosted tree model (XGBoost) turns them into odds for three classes: human, moderate bot and advanced bot.

Read it, then try to break it

Browse normally for ten seconds and watch the verdict settle. Then run one of the scripts in the panel and compare. The model only sees the measurements. It never sees which button you pressed.

A fair warning about the model

It learned from a small set of real sessions and a larger set of simulated bots, so it is strongest against bots that resemble the simulated ones. A script that moves smoothly and clicks slowly is the hard case. The panel shows which measurements drove each verdict, so you can judge it for yourself.

Clicking the ads is fine. Clicks are part of the signal.
